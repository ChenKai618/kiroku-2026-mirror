> 書類が完璧でも、これを押さなければ10月末に手元は空になる。

## 📋 登録する3社（この組み合わせが最適）

| # | サービス | 種別 | なぜこれか | 登録優先度 |
|---|---|---|---|---|
| 1 | **ビズリーチ** | スカウト型 | **登録するだけで「市場がお前をいくらで買うか」が分かる**。年収交渉の根拠になる | ★★★ 最優先 |
| 2 | **レバテックキャリア** | IT特化 | 技術が分かる担当者。AWS資格とクラウド移行案件を「正しく」売り込める | ★★★ |
| 3 | **リクルートエージェント** or **doda** | 総合大手 | 求人量が圧倒的。カテゴリー1/2の大企業案件が多い | ★★ |

### なぜ3社なのか
- 1社だけ → その担当者の質と相性に全賭けになる。ハズレたら終わり
- 5社以上 → 面談・日程調整・連絡対応で疲弊する。応募が重複する
- **3社が管理可能な上限**

### ⚠️ 重複応募の絶対ルール
**2社のエージェントが同じ会社に応募すると、通常その場で落ちる。**
企業側から見て「管理できていない候補者」に見えるため。
→ **`応募管理表.md` を必ず自分で管理する。エージェントは他社の動きを知らない。**

## 🔧 登録の実際の手順（各20〜30分）

### ① ビズリーチ（水曜にやる・最優先）

**なぜ最優先か**：これは「応募する」サービスではなく「**待つ**」サービス。
登録した瞬間から企業とヘッドハンターがお前のプロフィールを見て、
「年収○○万でどうか」というスカウトを送ってくる。

**つまり登録するだけで、お前は自分の市場価格を知ることができる。**
これは年収交渉で最強の武器になる。「他社からは○○万でスカウトが来ています」は事実の提示だ。

**登録時の入力ポイ**：
```
現在の年収：300万円 ← 正直に書く（後で源泉徴収票で確認される可能性がある）
希望年収：450万円   ← 目標より少し上を書く。ここは「希望」なので高めでいい
職種：      ソフトウェアエンジニア／クラウドエンジニア／インフラエンジニア
             ※複数選べるなら全部選ぶ。スカウトの母数が増える
経験社数：  2社
スキル：    Java, AWS, C#, TypeScript, Python, React
資格：      AWS SAP, AWS SAA, AWS CLF, JLPT N1
語学：      中国語（ネイティブ）／日本語（ビジネスレベル・N1）
```

**職務要約欄**（ここが一番読まれる。`02_書類/職務経歴書.md`から流用）：
```
損害保険会社向け基幹システムのAWS移行案件に開発メンバーとして参画。
外部設計・内部設計からテストまで一貫して担当。
移行先環境の理解のためAWS認定をCLF/SAA/SAPまで取得。
業務外でも個人開発を継続し、2026年以降4プロジェクトを実装・2件を公開稼働。
日本語N1・中国語ネイティブ。
```

**登録後にやること**：**何もしない。待つ。**
1〜2週間でスカウトの傾向が見える。その提示年収が**市場価格の答え**だ。

### ② レバテックキャリア（木曜）

**特徴**：IT・Web系専門。担当者が技術を理解している（ここが総合型と違う）。
お前の「AWS移行案件 + SAP資格 + 上流工程」を**正しい相手に売れる**。

**登録の流れ**：
1. 公式サイトから会員登録（5分）
2. 職務経歴を入力 or 職務経歴書PDFをアップロード
3. **カウンセリング（面談）の日程を予約** ← ここまでやって初めて動き出す
   - **オンライン可・平日夜間可・土曜可**
   - 「平日19時以降 or 土曜」で予約する（会社を休まない）

**この会社に特に伝えるべきこと**：
> 「クラウド・インフラ系のポジションを中心に見たいです。
> AWS認定を取得しており、現場でもオンプレからAWSへの移行案件に入っています。」

**理由**：`README.md` の狙う職種で書いた通り、**クラウド職はお前のAWS資格が唯一「換金」できる場所**。
IT特化エージェントはこの手のポジションを大量に持っている。

---

### ③ リクルートエージェント or doda（木曜）

**特徴**：求人数が最大級。**カテゴリー1/2の上場企業案件が多い**のがここの価値。
（在留資格更新の観点で、上場企業＝提出書類が原則不要）

**登録の流れ**：レバテックとほぼ同じ。面談予約まで進める。

**この会社に特に伝えるべきこと**：
> 「上場企業、または規模の大きい会社を優先したいです。
> 在留資格の更新が入社後すぐにあるため、
> 手続きに慣れている会社の方が安心という事情があります。」

**これは正直に言っていい。** むしろ言うべきだ。
エージェントは「外国人採用に慣れている会社」のリストを持っている。

## 🎤 エージェント面談の台本（1〜1.5時間）

### 面談で相手が知りたいこと（3つだけ）
1. お前は何ができるか（＝どこに売れるか）
2. お前は何を望んでいるか（＝どこに紹介すべきか）
3. お前はいつ動けるか（＝案件のタイミング）

### ⚠️ 面談の前に知っておくべき構造（重要）

**エージェントは、お前が入社したときに企業から手数料をもらう。**
相場は**年収の30〜35%**。つまり：

- お前が年収400万で入社 → エージェントの収入は約120〜140万
- お前が年収300万で入社 → エージェントの収入は約90〜105万

**だからエージェントは、お前の年収を上げたいというインセンティブを持っている。** これは味方。

**しかし同時に、「決まらないと1円にもならない」というインセンティブもある。**
だから終盤で「この条件で決めましょう」と圧をかけてくることがある。

**対処法**：**内定を承諾する期限は自分で決める。** エージェントの都合に合わせない。
「家族と相談してから決めます」は日本で完全に通る断り文句だ。

### 冒頭の自己紹介（2分・これを暗記しろ）

```
「陳凱と申します。よろしくお願いいたします。

2026年に中国から来日し、現在は損害保険会社向けの基幹システムを
オンプレミスからAWSへ移行する案件に、開発メンバーとして参画しています。
外部設計・内部設計からテストまで、上流から下流まで一通り経験させていただきました。

前職は中国で、C#とWPFを使った業務システムの開発を2年間担当しておりました。

現在は契約社員として有期契約で就業しており、
2026年11月30日で契約期間が満了いたします。
このタイミングで、正社員として腰を据えてキャリアを築ける環境に
移りたいと考え、ご相談させていただきました。

技術面では、現場がAWS移行案件だったこともあり、
AWS認定資格をCLFからSAPまで取得しております。
日本語は日本語能力試験のN1を取得しており、
現場では日本語で設計書の作成や業務を行っております。」
```

**この台本の設計意図**：
- 「損害保険」「AWS移行」「上流工程」を**最初の30秒で出す** ← ここが商品価値
- 「契約満了」を先に言う ← **短期離職の懸念を先に消す**
- 前職の不満を**一言も言っていない**
- 「日本語で設計書を作成」＝ 具体的な証拠（「日本語できます」より強い）

### 必ず聞かれる質問と、答え方

#### Q1「転職理由を教えてください」

```
「契約期間の満了が一番大きな理由です。

現在は契約社員で、1年ごとの有期契約という形なのですが、
やはり長期的に技術を積み上げていける環境で働きたいと考えております。

また、現在の案件では上流工程を経験させていただけて非常に良かったのですが、
AWS周りは基盤チームが担当している体制でして、
自分でクラウドの設計・構築まで踏み込める環境に行きたい、
というのが技術面での希望です。」
```

**✅ ここでやっていること**：
- 「契約満了」という反論不能な事実を主軸に
- 前職への不満を**技術的な向上意欲**に転換
- **給与への不満を一言も言っていない**（言うと「金だけの人」と見られる）

**❌ 絶対に言うな**：
- 「給料が新卒レベルで安すぎる」（事実だが、面接で言うと減点）
- 「社長が資格の費用を出してくれない」（愚痴に聞こえる）
- 「日本語も技術も自分より下の人が高給をもらっている」（**最も危険。他人と比較する人に見える**）

> 💡 **年収の話はここではしない。オファー面談でする。**
> ただしエージェントには**本音を言っていい**（後述）。彼らは味方だから。

---

#### Q2「希望年収はいくらですか」★ここが最重要

**⚠️ この質問への答え方を間違えると、後から取り返せない。**
詳細は `07_年収交渉/希望年収の答え方.md` に書いたが、要点だけ：

```
「現在が300万円です。

正直に申し上げますと、来日時に『日本での経験がゼロだから』ということで
新卒と同じ条件で入社しており、
市場水準と比べてどうなのかを把握できていない部分があります。

まずは私の経験とスキルで、市場ではどのあたりが妥当なのか、
プロの目線で教えていただけると助かります。

その上で希望としては、450万円程度を目指したいと考えておりますが、
仕事の内容や環境も含めて総合的に判断したいと思っております。」
```

**この答え方の設計**：
1. **現年収は正直に言う**（源泉徴収票で確認される可能性がある。嘘は危険）
2. **「新卒条件で入った」という事情を説明する** ← これが効く。「安い理由」が能力ではなく事情だと伝わる
3. **相手に市場価格を聞く** ← エージェントは答えてくれる。しかも彼らは高く売りたい。**タダで情報が取れる**
4. **その上で数字を出す**（450万＝目標400万より上に置く。交渉の余地を作る）
5. 「総合的に判断」＝ 金だけの人ではないと示す

---

#### Q3「いつから働けますか」

```
「現在の契約が11月30日に満了しますので、
12月1日からの入社が可能です。

有給も残っておりますので、
引き継ぎと合わせて調整できると思います。」
```

**✅ 「11/30満了 → 12/1入社」は空白ゼロの理想形。** エージェントも企業も好む。

---

#### Q4「他にどこを受けていますか」

```
「他にも数社のエージェント様にご相談しております。
まだ具体的な応募先は絞っているところです。」
```

**正直に「他社も使っている」と言っていい。** 隠すと重複応募事故が起きる。
ただし**どの会社に応募したかは言わない**（言う義務なし）。

### 逆にお前がエージェントに聞くべきこと（必ず聞け）

```
1. 「私の経歴で、市場ではどのあたりの年収レンジが妥当でしょうか？」
   → タダで市場価格が分かる。3社に聞けば相場が見える

2. 「クラウド・インフラ系のポジションで、私の経歴で応募可能な求人はありますか？」
   → AWS資格を換金できる求人があるか確認

3. 「上場企業、または規模の大きい会社の求人を優先していただけますか？
    在留資格の更新が入社後すぐにあるためです」
   → カテゴリー1/2の会社を引き出す

4. 「外国人の採用実績がある会社を優先していただけますか？」
   → ビザ手続きに慣れている会社が分かる

5. 「書類選考の通過率を上げるために、
    職務経歴書で直したほうがいい点はありますか？」
   → プロの添削がタダで受けられる。これは絶対に聞け

6. 「私の場合、日本での経験が短い点はどう見られますか？
    どう説明するのが良いでしょうか？」
   → 弱点への対処法を、売る側の視点で教えてもらえる
```

**5番と6番が特に重要。** エージェントはお前を売りたいので、
「どう書けば売れるか」を本気で教えてくれる。**これはタダのコンサルだ。**

### エージェントには本音を言っていい

**面接では言えないことを、エージェントには言える。** むしろ言うべきだ。

```
「実は、来日時に『日本での実務経験がゼロだから』と言われて
新卒と同じ給与で入社しました。

その後、現場で周りを見て、
自分の日本語力や技術に対して条件が合っていないのではないかと
感じるようになりました。

ただ、この事情を面接でどう説明すべきか分からず悩んでいます。
アドバイスをいただけますか？」
```

**なぜこれを言うべきか**：
- エージェントは「安く買われている人材」を**高く売り直すのが商売**。この情報は彼らの武器になる
- 「300万は能力ではなく事情による」と企業に説明してくれる
- 面接での説明方法をプロが設計してくれる

**ただし言うな**：社長個人への恨み、他の社員との比較、感情的な表現。
**事実と、それをどう説明するかの相談**に留める。

## 🚩 こういうエージェントは切っていい

| 危険信号 | 意味 |
|---|---|
| SES・派遣の求人ばかり紹介してくる | お前を「売りやすい商品」として扱っている。目標と逆方向 |
| 希望を聞かずに「まずこれ受けてみましょう」 | 数を回して確率で当てる方式。時間の無駄 |
| 「今の年収なら350万が妥当です」と即断 | 市場を見ていない。または安く早く決めたい |
| 内定を急かす・返答期限を勝手に短くする | 自分の月次目標のため。**お前の利益ではない** |
| 連絡が遅い・雑 | 企業への推薦も雑。書類が通らない |

**担当者は変更を依頼できる。** 「相性が合わない」で十分な理由になる。
遠慮するな。**お前が客だ**（正確には企業が客だが、お前がいないと商売にならない）。

## 📞 面談の実務メモ

- **服装**：オンラインならシャツで十分。スーツ不要
- **場所**：自宅から。**会社からは絶対に繋がない**
- **時間**：平日19時〜、または土曜。多くのエージェントが対応している
- **持ち物**：職務経歴書PDF（事前アップロード済みなら不要）
- **メモ**：紹介された会社名・年収レンジ・担当者名を必ず記録
- **録音**：しない方がいい（バレると信頼を失う）
