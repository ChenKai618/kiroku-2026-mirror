# スカウトの捌き方（ビズリーチ・スカウト型媒体）

> **スカウトが来始めたら開く。** 全部に返信する必要はないし、全部に返信すると潰れる。

---

## 🔴 返信より先にやること：数字を記録する

**スカウトの提示年収は、市場がお前をいくらで買うかの実データ。**
これがオファー面談での交渉根拠になる。**登録した本来の目的はこれ。**

`01_スケジュール/週次チェックリスト.md` に記録：

```
■ ビズリーチのスカウト状況（___月___日時点）
  受信件数：___件（うちプラチナ：___件）
  提示年収の範囲：____万 〜 ____万
  最高提示：____万（会社：__________）
  傾向：クラウド/インフラ___件 / SIer___件 / 社内SE___件 / SES___件 / その他___件
```

**現年収300万に対していくら来ているか。**
これを見てから、目標450万が保守的すぎたか妥当かを判断する。

> 💡 オファー面談で「エージェントから伺っている市場水準」ではなく
> **「実際にこの額でスカウトをいただいています」** と言えるのが強い。事実の提示だから。

## 本物と一斉配信の見分け方

| 見分け方 | 本物 | 一斉配信 |
|---|---|---|
| **固有の経験に触れているか** | 「損保の基幹システム」「AWS移行」「上流工程」「N1」等が本文にある | 「ご経歴を拝見し」だけ |
| **年収が具体的か** | 「450〜600万」など範囲が明示 | 記載なし／「応相談」 |
| **プラチナスカウトか** | ★送信数に上限があるため本気度が高い | 通常スカウトは無制限 |
| **面接確約が付いているか** | ★**書類選考をスキップできる** | なし |
| **求人が特定されているか** | 具体的な求人票へのリンクがある | 「多数のポジションがあります」 |

### ★「面接確約付きプラチナスカウト」を最優先する理由

**日本での実務経験が5ヶ月しかないため、最大の関門は書類選考。**
面接確約はそこを飛ばせる。**面接まで行けば、
損保基幹システム・上流工程・AWS SAP・N1 で戦える。**

書類だけで判断されると「在日5ヶ月」で切られやすい。**会えれば勝率が上がる。**

## 4つに仕分ける

### ① 即返信（優先度 最高）
- 上場企業 or 中堅以上（＝**カテゴリー1/2**。在留更新の書類が原則不要）
- クラウド／インフラ／社内SE のポジション
- 提示年収 **400万以上**
- 面接確約付き

### ② 返信するが優先度は下げる
- 提示 370〜400万だが、上場企業かつクラウド職
- 事業会社の社内SE（年収は普通でも在留更新が楽・上流中心）

### ③ 情報だけもらう
- 提示年収の記載がない大手 → **「想定年収を教えてください」だけ返す**
- 興味はあるが今は判断できない → カジュアル面談だけ受ける

### ④ 返信しない
- ❌ **SES・派遣・客先常駐** ← 今と同じ問題の繰り返し。[ADR-0004](../docs/adr/0004-target-by-visa-category.md)
- ❌ 提示 **350万未満**
- ❌ 業務内容が違う（営業・PM・テスター・ヘルプデスク等）
- ❌ 会社名が書かれていない（＝人材紹介会社の集客）
- ❌ 「未経験歓迎」「学歴不問」が前面に出ている求人

## ⚠️ ヘッドハンターからのスカウトには罠がある

ビズリーチのスカウトには **企業直接** と **ヘッドハンター（転職エージェント）** の2種類ある。

**ヘッドハンターのスカウトは「求人の案内」ではなく「うちに登録しませんか」という誘い。**

### 何が危険か

**レバテックキャリアと同じ企業に応募してしまう可能性がある。**
2社経由で同じ会社に出すと、**重複応募として通常その場で落選する。**
企業側から見て「管理できていない候補者」に見えるため。

### 対策：返信に必ずこの一文を入れる

```
なお、他のエージェント様経由でも活動しておりますので、
ご紹介いただく前に企業名をお教えいただけますでしょうか。
重複応募を避けたいと考えております。
```

**これを言うだけで、まともなヘッドハンターかどうかも分かる。**
嫌がる・はぐらかす相手は数を回しているだけなので切っていい。

### ヘッドハンターを増やしすぎない

既に レバテックキャリア ＋ 総合大手 を予定している。
**ビズリーチのヘッドハンターを足すなら1人まで。**
3〜4人が管理可能な上限で、それを超えると日程調整と重複管理で潰れる。

## 返信の型

### 興味がある場合（企業直接）

```
ご連絡いただき、誠にありがとうございます。

【求人票から拾った、その会社固有の事実】に大変興味を持ちました。

現在は損害保険会社向け基幹システムのオンプレミスからAWSへの移行案件に
開発メンバーとして参画しており、今後はクラウド領域で設計から構築まで
携われる環境で専門性を積み上げたいと考えております。

まずはカジュアル面談などでお話を伺えますと幸いです。
平日は19時以降、または土曜日であれば調整が可能です。

何卒よろしくお願いいたします。
```

**2箇所が重要：**

| 箇所 | 理由 |
|---|---|
| **【】をその会社固有の内容に書き換える** | ここが空だとテンプレ返信だと即バレる。技術ブログ・製品名・事業内容から1つ拾う |
| **「平日19時以降、または土曜」を1通目に入れる** | **10月まで有給がない。** 昼間に組まれると欠勤控除になる（契約書第3条③）。最初に枠を示せば自然に調整される |

### 年収が書かれていない場合

```
ご連絡いただき、誠にありがとうございます。

ポジションについて詳しくお伺いしたく存じます。
差し支えなければ、想定年収のレンジと、
クラウド・インフラ領域にどの程度携われるポジションかを
お教えいただけますでしょうか。
```

**年収を聞くのは失礼ではない。** スカウト型媒体では標準的なやり取り。

### 断る場合

```
ご連絡いただきありがとうございます。

大変ありがたいお話ではございますが、
現在はクラウド・インフラ領域のポジションを中心に検討しておりますため、
今回は見送らせていただきたく存じます。

貴重な機会をいただき、ありがとうございました。
```

> 💡 **返信しなくても失礼ではない**（スカウトは営業だから）。
> ただし業界は狭いので、丁寧に断ると後で別の求人で再度声がかかることがある。

## 件数の上限（潰れないため）

**全部に返信するな。9週間しかないし、面接は1日2件が上限。**

| 項目 | 上限 |
|---|---|
| 返信 | **週5〜8件** |
| カジュアル面談 | **週2〜3件** |
| 面接 | **1日2件まで** |

**本命は後半に受ける。** 前半のカジュアル面談で場慣れする。
5社受ければ聞かれる質問はほぼ出尽くす → `05_面接/想定問答集.md`

## 🔴 応募したら必ず記録する

`06_エージェント/応募管理表.md` に、**経路も含めて**記録する。

```
| 会社名 | 経路 | 職種 | カテゴリ | 想定年収 | 応募日 | 書類 | 一次 | ... |
|--------|------|------|---------|---------|-------|-----|-----|-----|
| ○○     | ビズリーチ直接 | クラウドエンジニア | 1（上場） | 450-550万 | 9/5 | ○ | | |
| △△     | レバテック | インフラ | 2 | 420-500万 | 9/6 | 待 | | |
```

**ビズリーチ経由・レバテック経由・ヘッドハンター経由が混ざると、重複応募事故が起きる。**
エージェントは他社の動きを知らない。**台帳を持てるのは自分だけ。**

## 会社を調べてから返信する

興味のあるスカウトが来たら、**返信前に私に頼め**：

```
「この会社を調べて：（会社名 or 求人URL）」
```

調べること：上場しているか（＝カテゴリー1か）・従業員数・事業内容・
SES/受託/自社開発/事業会社のどれか・外国人採用の実績・
想定年収の内訳（固定残業の有無）・クラウドの体制。

**特に「上場しているか」は在留更新の負担に直結する。**
入社2ヶ月後に更新申請があるため、カテゴリー1/2なら追加書類が原則不要。
→ [ADR-0004](../docs/adr/0004-target-by-visa-category.md)

## 2週間後に設定を見直す

スカウトの傾向を見て、希望条件を調整する：

| 届いたスカウトの傾向 | 対応 |
|---|---|
| SES系が大半 | 希望職種の「SE（Web・オープン系）」を「サーバーエンジニア」に入れ替える（母数を捨てて純度を取る） |
| インフラ系がゼロ | 希望業種の「ソフトウエア」を「通信・キャリア」に入れ替える |
| 全体が少ない | 希望年収500万を下げる、または他2社に注力する |
| 提示額が想定より高い | **目標年収を上方修正する。450万が保守的すぎた可能性** |

**設定は何度でも変えられる。実際に届いたスカウトが、どんな推測よりも正確な情報を返す。**
