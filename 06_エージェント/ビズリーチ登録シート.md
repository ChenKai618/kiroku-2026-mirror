### なぜこの書き方なのか

**「公的機関」は事実である。** 架空の企業名を作らない理由は
[ADR-0003](../docs/adr/0003-no-factual-fabrication.md) に記録済み——
入社2ヶ月後に在留期間更新許可申請を出すことになり、
申請書には職歴を記入する欄がある。**民間の履歴書の虚偽が入管の法定文書に転記される。**

そして**架空の会社を作る方が運用コストが高い。**
業種は／何名規模／製品は／なぜ辞めた／在職証明は出せるか——
この連鎖に日本語で、圧力下で、複数社に対して一貫して答え続ける必要がある。

**「守秘義務によりお答えできません」は日本の職場で尊重され、そこで会話が終わる。**

### 面接で深掘りされたときの回答（暗記しろ）

```
「国防関連の公的機関でしたので、
詳細は守秘義務の関係でお話しできません。

技術的には C# と WPF を用いた業務システムの開発を担当し、
要件の整理から設計・実装・保守まで一通り経験いたしました。」
```

**これで追及は止まる。** そして「話せない経歴を持つ人」という
**記憶に残る個性**になる。面接で覚えてもらえること自体が得点だ。

**ビズリーチには入会審査があり、全体的に高年収層向けのサービスだ。**

現年収300万・在日6ヶ月という条件では、
**審査に通らない、または通ってもスカウトが少ない可能性がある。**

**それは失敗ではなく、情報だ。** そしてどちらの結果でも計画は変わらない：

- 審査に通った → **スカウトの提示額が市場価格の答え**。年収交渉の根拠になる
- 通らなかった／スカウトが少ない → **レバテックキャリアと総合大手に集中する**。
  この2社は審査の性質が違う

**ここで詰まっても粘るな。** 次の2社に進め。
スカウト型は「登録して待つ」のが役割であって、時間をかける場所ではない。

## 登録後にやること

**何もしない。待つ。**

1〜2週間でスカウトの傾向が見える。記録する場所は
`01_スケジュール/週次チェックリスト.md` の Week 2：

```
■ ビズリーチのスカウト状況
  受信件数：___件
  提示年収の範囲：____万 〜 ____万
  最高提示：____万（会社：__________）
```

**この数字が、オファー面談での交渉根拠になる。**
「エージェント様から伺っている市場水準」ではなく、
**「実際にこの額でスカウトが来ている」は事実の提示だ。**

そして次へ：**レバテックキャリア（IT特化）と、リクルートエージェント or doda（総合大手）。**
3社揃って初めて時計が動き出す。
