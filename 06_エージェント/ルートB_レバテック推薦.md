# ルートB：純推薦型（レバテック サジェスト/検討中）

> **このルートの開始方法（コピペ用）**
> ```
> 06_エージェント/ルートB_レバテック推薦.md を読んで、
> レバテックの未選定の新着を調査してください。
> ```
> **URL**
> - 未選定（サジェスト）：`https://mypage.levtech.jp/recruits/suggested`
> - 検討中：`https://mypage.levtech.jp/recruits/considering`
> - 選考中（応募済み）：`https://mypage.levtech.jp/recruits/screening`
> - 対象外：`https://mypage.levtech.jp/recruits/excluded`
>
> **対象**：レバテック（`mypage.levtech.jp/recruits/suggested`）
> **チャネルの性質**：エージェント（レバテック）が**あなたの経歴に基づいて推薦してくる**求人。母数は限られる。
> **データ本体**：`レバテック求人台帳.md`（このファイルは実行手順と最新状態のサマリ）
> **判定基準**：`求人スクリーニングプロンプト.md`（v3.2）＋`会社スクリーニング基準.md`（v3.1）

---

## 1. このルートの特徴

- **母数が限られる**（サジェストは数十件規模）。→ **出尽くしたら終わり**。全件を通常調査する
- レバテックは**IT特化エージェント**で、非公開求人を持つ。DODA/BizReachより質は高い傾向
- タブ構成：**未選定 / 検討中 / 選考中 / 対象外**の4つ
  - 未選定＝未判定の新着 → ここを調査する
  - 検討中＝応募候補としてマーク済み
  - **選考中＝応募済み**（猎头が正式応募を出した）
  - 対象外＝見送り

## 2. 調査手順

1. `suggested`（未選定）を開き、**前回調査以降の新着IDのみ**を抽出（IDを記録済みの一覧とdiff）
2. 新着について `求人スクリーニングプロンプト.md` v3.2 の手順：
   - **一覧カードで判定しない。必ず詳細ページを開く**（カードの「正社員」「リモート可」は当てにならない）
   - 雇用形態に「派遣」「無期雇用派遣」／勤務地に「常駐」「顧客先」／事業内容に「労働者派遣事業 許可番号」がないか
   - 固定残業・実質年収（基本給ベース）
   - クラウド接触度（高/中/低）＋根拠1行
3. 判定：✅本命 / ⚠️挑戦 / ❌見送り / 🔻FB
4. 4層タグを付ける：🚀冲刺 / 🎯主战场 / 🌉桥梁（`応募の動かし方` v3.1）
5. 応募依頼したものは「検討中」→「選考中」へ。トラッカー：`応募管理表.md`
