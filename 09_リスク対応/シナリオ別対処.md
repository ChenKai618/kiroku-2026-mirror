# リスク対応 — シナリオ別対処法

> **パニックになる前にここを開け。** 全部、事前に対処法がある。

---

## 🚨 シナリオ1：社長に転職活動がバレた

### まず落ち着け。バレても致命的ではない

**理由**：お前の契約は**2026年11月30日で満了する有期契約**だ。
契約満了は法律上の自然な終了であり、会社に阻止する権限はない。

### 会社ができること / できないこと

| 会社ができること | 会社ができないこと |
|---|---|
| 契約を更新しない（→ お前も更新したくないので問題なし） | **契約期間中の一方的な解雇**（労契法17条：有期契約は「やむを得ない事由」がなければ期間中の解雇は不可） |
| 現場から外して自宅待機（第5条）| **無給での自宅待機**（労基法26条：会社都合の休業は**平均賃金の6割以上**の休業手当が必須。契約書に「無給」と書いてあっても**無効**） |
| 嫌味を言う | 転職の阻止 |
| 入管に「離職した」と届出（法定義務なので当然やる） | 入管に虚偽の申告（これは会社側の違法行為） |

### 対応の台本

```
「転職活動をしているのは事実です。

現在の契約が11月30日で満了するとお聞きしておりますので、
その後のキャリアについて準備を進めております。

契約期間中は、現場での業務に責任を持って取り組みます。」
```

**ポイント**：
- **謝るな。** 契約満了に向けた準備は正当な行為だ
- **感情的にならない**。事実を淡々と述べる
- 「契約が満了するから」という**会社が自分で書いた事実**を根拠にする

### やるべきこと
1. **この会話を記録する**（日付・場所・発言内容をメモ。スマホのメモでいい）
2. **現場での業務は絶対に手を抜かない**（懲戒の口実を与えない）
3. **給与明細を毎月保存**（後で揉めたときの証拠）
4. **転職活動を加速する**（バレたなら隠す必要が減る。夜間面接の制約が緩む）

## 🚨 シナリオ2：自宅待機を命じられた（無給と言われた）

### これは違法の可能性が高い

**労基法26条**：使用者の責に帰すべき事由による休業の場合、
**平均賃金の60%以上**の休業手当を支払わなければならない。

**契約書第5条「無給にする場合もある」は、この規定に反する部分は無効。**
（労基法13条：法に反する労働契約の部分は無効となり、法の基準が適用される）

さらに、**民法536条2項**により、会社の都合による就労不能なら
**賃金全額**を請求できる余地もある（判例あり）。

### 対応手順

**Step 1：書面で理由を求める**
```
「自宅待機の指示について、
理由と期間、および休業期間中の賃金の取扱いについて
書面でご説明いただけますでしょうか。」
```
> **書面を求めるだけで、多くの場合ここで止まる。** 会社は記録を残したくない。

**Step 2：それでも無給と言われたら**
```
「労働基準法26条により、
会社都合の休業には平均賃金の6割以上の休業手当が必要と理解しております。
ご確認いただけますでしょうか。」
```

**Step 3：それでも払われない場合**
- **労働基準監督署**に相談（無料・匿名相談可）
  - 東京労働局 総合労働相談コーナー
  - 「賃金不払い」は監督署の管轄
- **「総合労働相談コーナー」**は外国語対応もある

**Step 4：並行して転職を最優先に**
自宅待機になったら、**時間ができる**。それを面接に全部使え。
（皮肉だが、これは転職活動の時間が増えるということだ）

### ⚠️ ただし、現実的な判断も必要
争えば勝てる可能性は高い。だが**争っている間に時間と精神力を失う。**
残り3ヶ月なら、**争わずに転職を急ぐ方が合理的**な場合が多い。
証拠だけ保全して、次に進むのも正しい選択だ。

## 🚨 シナリオ3：損害賠償をちらつかされた（第7条）

### 契約書第7条①の文言

> 乙の都合により、本契約を終了する場合、必ず顧客の合意を得なければならない。
> 顧客の合意が得られないまま契約を終了した場合、
> そのために甲がこうむった一切の損害を乙が損害賠償しなければならない。

### この条項が問題にならない理由

**① そもそも適用されない**
この条項は「**本契約期間中に**、プロジェクトの途中で」辞める場合の規定。
**11月30日の契約満了は「契約期間中の解約」ではない。** 条項の射程外。

**② 適用される場面でも、法的に極めて弱い**
- **労基法16条**：賠償予定の禁止
- **憲法22条1項**：職業選択の自由 — 「顧客の合意」を退職の条件にすることは、
  第三者に労働者の退職拒否権を与えるに等しく、公序良俗違反（民法90条）の可能性が高い
- **茨城石炭商事事件（最判昭51.7.8）**：会社が従業員に損害賠償を請求できるのは
  「損害の公平な分担という見地から**信義則上相当と認められる限度**」に限られる
  → 「後任を探す費用」程度では、裁判所はほぼ認めない

**③ 実際に訴訟になる可能性はほぼゼロ**
- 訴訟費用が請求額を上回る
- 会社側が負ける可能性が高い
- 労基署・裁判所の記録に残ることを会社が嫌う

**これは「脅すための条項」であって「実行するための条項」ではない。**

### 言われたときの対応

```
「契約書を確認しましたが、第7条は
『契約期間中に、プロジェクトの途中で終了する場合』の規定と理解しております。

私の場合は、第1条に定められた契約期間が
11月30日に満了することによる終了ですので、
この条項には該当しないと考えております。」
```

**冷静に、契約書の文言を引用する。** これが最も効く。
相手は自分が書いた文章に反論できない。

### それでも執拗な場合
- **「では書面でご説明いただけますか」** → ほぼ止まる
- 労働局の**総合労働相談コーナー**（無料）
- 法テラス（収入条件により無料法律相談）

## 🚨 シナリオ4：10月末までに内定が出ない

### **更新しろ。これは敗北ではない。**

**理由**：
- 在留期限が2027年2月末。**更新申請には雇用先が必須**
- 無職では申請書類（雇用契約書・在職証明書・会社の登記事項証明書・決算文書）が揃わない
- **申請できない＝在留期限で日本にいられなくなる**

### 更新した場合の新しい時間軸

```
2026/11/30  契約更新 → 2027/11/30 まで
2026/12〜   在留期間更新申請（現会社で。実績があるので通りやすい）
2027/02     在留期限 → 更新されて延長
2026/12〜   転職活動を継続（時間の余裕ができる）
2027/夏     再度、余裕を持って転職（次の満了は2027/11）
```

**更新するメリット**：
- 在籍期間が**1年を超える** → 短期離職の懸念が完全に消える
- 焦らずに選べる → **安いオファーを断れる**
- 現場経験が長くなる → 職務経歴書が強くなる（設計〜テスト完遂の実績）
- **時間を買える**

### 更新するときの伝え方
特に何も言わなくていい。「更新をお願いします」で終わり。
転職活動をしていたことを説明する義務はない。

### ⚠️ ただし条件は付けろ
更新のタイミングは**昇給交渉の唯一のチャンス**だ（契約書第4条：昇給は1年ごと）。

```
「更新をお願いしたいと考えております。

つきましては、契約書第4条の昇給についてご相談させていただけますでしょうか。
入社後、外部設計から内部設計、単体テストまで担当させていただき、
AWS認定資格も3つ取得いたしました。
現場からの評価も含めて、ご検討いただけますと幸いです。」
```

**断られてもいい。聞くのは自由だ。** そして断られたら、
それは「来年は必ず出る」という決意の材料になる。

## 🚨 シナリオ5：内定は出たが年収が低い（350万など）

### 判断基準を今のうちに決めておけ

| 提示額 | 判断 |
|---|---|
| **450万以上** | ✅ 即受諾を検討 |
| **400〜450万** | ✅ 受諾。ただし1回は交渉してみる |
| **370〜400万** | ⚠️ 交渉必須。他の要素（正社員・カテゴリー1/2・クラウド職）が良ければ受諾も |
| **350万前後** | ⚠️ 慎重に。**現在+50万だが、また同じ問題を繰り返す危険** |
| **350万未満** | ❌ 断って更新する方が正しい |

### 350万前後で悩んだときの考え方

**単純な金額差だけで判断するな。以下を総合しろ**：

| 加点要素 | なぜ |
|---|---|
| **正社員である** | 有期契約からの脱出。これ自体に大きな価値 |
| **カテゴリー1/2の会社** | 在留資格更新が「書類なし」で通る。次回3年の可能性 |
| **クラウド/インフラ職** | AWS資格が活きる。次の転職で年収が跳ねる |
| **自社開発/事業会社** | SESから脱出。多重下請けの外に出る |
| **賞与が月数で明記** | 「業績により決定」ではない＝実際に出る |
| **資格取得支援あり** | 実質的な年収アップ（AWS受験料は1回3〜4万） |
| **昇給制度が明確** | 2年目・3年目の伸びが読める |

**「350万＋正社員＋上場企業＋クラウド職」は、「400万＋契約社員＋小規模SES」より価値が高い。**

### 断るときの文面
```
「このたびは内定をいただき、誠にありがとうございました。

大変ありがたいお話ではございますが、
慎重に検討させていただいた結果、
今回は辞退させていただきたく存じます。

貴重なお時間をいただきましたこと、心より御礼申し上げます。」
```
> 理由を詳しく書く必要はない。恨みを買わない文面にする（業界は狭い）。

## 🚨 シナリオ6：面接で経歴を深掘りされて詰まった

### その場での対処

```
「申し訳ございません、
今すぐ正確にお答えできる自信がないので、
確認してから改めてご回答させていただけますでしょうか。」
```

**これは減点だが、致命傷ではない。** 適当に答えて矛盾するより**はるかにいい。**

### 特に注意すべき深掘りポイント

| 聞かれたら | 正直に答える |
|---|---|
「AWSの構築経験は？」 | 「基盤チームの担当で、私は開発側です。構築そのものの経験はありません」 |
「設計は主導した？」 | 「先輩と一緒に進めていました。私が主導したわけではありません」 |
「2019-2021の機関名は？」 | 「守秘義務の関係でお話しできません」 |
「個人開発のコードは全部理解している？」 | 「AIを使って実装した部分もあります。設計判断は自分でしていて、ADRに残しています」 |

**「できない」「していない」を正直に言うのは減点ではない。**
**嘘をついて崩れるのが致命傷だ。**

### 面接後にやること
詰まった質問を `05_面接/想定問答集.md` に追記して、**翌日までに答えを作る。**
同じ質問は必ず他社でも出る。**5社受ければ質問は出尽くす。**

## 🚨 シナリオ7：入社直後の在留期間更新が不安

### 手続きの流れ（`08_手続き/` に詳細）

```
2026/11/30  現契約満了
      ↓ 14日以内
2026/12/14  【必須】契約機関に関する届出（入管法19条の16）
      ↓
2026/12/01  新会社入社
      ↓ 推奨
2026/12月中 就労資格証明書交付申請（任意・2,000円 / オンライン1,600円）
      ↓
2026/11末〜 在留期間更新許可申請（期限の3ヶ月前から可能）
2027/02/28  在留期限
```

### ⚠️ 忘れると罰金になるもの

**契約機関に関する届出**（入管法19条の16第2号）：
- **期限：事由発生から14日以内**
- 退職と入社の両方について届出が必要
- **未届出の罰則：20万円以下の罰金**（入管法71条の5第3号）
- **虚偽届出：1年以下の拘禁刑 または 20万円以下の罰金**（71条の2第1号）
- さらに更新審査で**マイナス評価**（在留期間が短縮される要因になる）
- **提出方法**：インターネット（電子届出システム）／郵送／窓口
- **添付書類は不要**（在留カードの写しのみ）

### 就労資格証明書を取るべき理由

**任意だが、強く推奨。** 理由：

これは**転職後・次の更新前に、入管に「新しい仕事が現在の在留資格の範囲内か」を事前判定してもらえる唯一の手段**。

取らない場合のリスク：
新しい職務の該当性が**初めて審査されるのが次の更新時**になる。
そこで「該当しない」と判断されたら**更新不許可 → 離職 or 帰国**。
その時点で既に1年働いている。**損失が巨大。**

- **手数料**：窓口2,000円 / オンライン1,600円（2025年4月改定）
- **処理期間**：転職など変更がある場合 1〜3ヶ月
- **入管法19条の2第2項**：これを提示しないことを理由に不利益な取扱いをすることは**禁止**されている

### 無職期間について（正確な理解）

**入管法22条の4第1項第6号**：
在留資格に応じた活動を**継続して3ヶ月以上**行わないでいると、
在留資格を**取り消されることがある**。
ただし「**正当な理由がある場合を除く**」（条文に明記）。

**求職活動は正当な理由に該当する**と解されている（行政書士の実務解釈で一致）。
ただし**証拠が必要**：応募記録・面接記録・エージェント利用記録を残せ。

**⚠️ 重要な誤解を正す**：
これは**在留資格の「取消」を防ぐ**規定であって、
**在留期限を延長する規定ではない。**

**期限は2027年2月28日で、これは動かない。**
期限までに更新申請を出さなければ、不法残留になる。
そして**更新申請には雇用先が必須**。

**→ だから「無職でも3ヶ月大丈夫」ではない。お前の場合、無職の余裕はゼロだ。**

### 特例期間（覚えておくと安心）
**入管法20条6項**：在留期限**前**に更新申請を受理されていれば、
処分が出るまで、または**期限満了から2ヶ月**（いずれか早い方）まで
**従前の在留資格で在留・就労を継続できる**。

→ 2027年2月末までに申請を出せば、**4月末までは安全**。
**だが申請を出すには会社が必要。** 結論は変わらない。

## 🚨 シナリオ8：体調・メンタルが崩れた

**10週間の転職活動は消耗する。** 特に：
- 日本語で技術を語る緊張
- 書類選考の落選（**3割通過が普通。7割落ちる**）
- 会社に隠しながらの二重生活

### 予防策
- **1日2件以上の面接を入れない**
- **落選は個人攻撃ではない**。マッチングの問題。**7割落ちるのが正常**
- 週1日は転職のことを考えない日を作る
- 現場が暇なのは**今は資産**。体力を残せている

### 崩れたときの判断
**「更新して来年やり直す」は常に有効な選択肢だ。**
在留資格が守られていれば、時間は買える。
**無理をして安いオファーを受けるより、更新して立て直す方が正しい。**
