## 🚫 絶対に忘れてはいけない約束事

### 1. 会社の誰にも転職を悟られない（〜10月末）

**理由**：契約書 **第5条**「自宅待機の期間は休業となり、無給にする場合もある」
→ 現場から外されれば、**収入と「MS&AD案件参画中」という最大の武器が同時に消える**。

具体的に：
- 同僚・現場の中国人・社長、誰にも言わない
- 9月は極力有給/欠勤を取らない（有給は10/1発生。それまで休む＝欠勤控除）
- 面接は**夜間・土曜**を優先（カジュアル面談は元々夜が多い）
- **会社のPCで転職活動をしない**（絶対）→ 詳細は `01_スケジュール/日次タイムテーブル.md`
- 職務経歴書に**顧客名（MS&AD・NTTデータ）を書かない** → 「損害保険会社向け」「大手SIer元請案件」と書く

> 💡 **9月中旬の昇給交渉は、意図せず最良のカモフラージュになる。**
> 転職を決めている人間は、現職の給与交渉をしない。→ `07_年収交渉/現職への昇給交渉.md`

### 2. 経歴の「事実欄」は動かさない

**修辞は自由に盛れ。事実欄は動かすな。** この線引きが全て。

| 盛ってOK（標準的な書き方） | 絶対NG（在留資格リスク） |
|---|---|
| 「設計レビューへの参加」（実際は先輩の横で聞いていた） | 存在しない会社名 |
| 「既存システムのソースコード解析」（実際は旧コードを読んだ） | 在籍期間の改ざん |
| 「移行方式の検討に関与」 | 学歴の年次改ざん |
| 「12名体制の開発チームに所属」 | 前職年収の大幅な虚偽 |

**理由**（道徳論ではなく、リスク計算）：
入社2ヶ月後（2026年12月〜2027年2月）に**在留期間更新許可申請**を出す。
申請書には**学歴と職歴を書く欄がある**。
民間の履歴書に書いた嘘を、2ヶ月後に自分で入管の法定文書に転記することになる。

- 日本人が経歴詐称 → 最悪、懲戒解雇（炭研精工事件 最判平3.9.19）
- **外国人が入管申請で経歴を偽る** → 入管法22条の4第1項第2号 → **在留資格取消 → 出国準備期間なしの退去強制 → 原則5年間上陸拒否**

しかも入管は**2025年のCOE申請時に提出した書類を全て保管している**（ISA公式：「原則として、提出された資料は返却できません」）。

**そして、そもそも盛る必要がない。** 手持ちの本物のカードで十分足りる（下記）。

### 3. 2019-2021の書き方は「公的機関」で確定

```
2019年4月 〜 2021年3月
公的機関にて業務システム開発（C# / WPF）
```

深掘りされたら：
> 「国防関連の公的機関でしたので、詳細は守秘義務の関係でお話しできません。
> 技術的にはC#とWPFを用いた業務システムの開発を担当しておりました。」

これは**真実**であり、日本の職場で尊重される回答であり、**会話がそこで終わる**。
架空の会社を作れば「業種は？何名？なぜ辞めた？在職証明は？」の連鎖に晒される。

### 4. 面接での退職理由は「契約満了」一本

```
「現在は契約社員として有期契約で就業しており、2026年11月30日で契約期間が満了します。
このタイミングで、腰を据えて長期的にキャリアを築ける環境に移りたいと考えました。」
```

- **前職の悪口は絶対に言わない**（日本の面接で最大級の減点）
- 給与への不満、社長への不満は**一切口に出さない**
- 「契約満了」は日本で最も無敵の転職理由。**短期離職の懸念を消してくれる**

## 🎯 狙う会社の優先順位

**最重要の新事実**：入社2ヶ月後に在留期間更新がある。
**新会社の「カテゴリー」で提出書類が10倍変わる。**

| カテゴリー | 定義 | 更新時の提出書類 |
|---|---|---|
| **カテゴリー1** | 上場企業・公益法人等 | **原則、追加書類なし** ✅ |
| **カテゴリー2** | 前年源泉徴収税額1,000万円以上（≒中堅以上） | **原則、追加書類なし** ✅ |
| カテゴリー3 | 一般の中小企業 | 登記事項証明書・会社案内・**決算文書**・雇用契約書・課税/納税証明書 |
| カテゴリー4 | 新設・零細 | 同上＋審査厳格化 ⚠️ |

さらに **2026年4月15日以降**、カテゴリー3・4は「所属機関の代表者に関する申告書」も追加。
**派遣形態での就労**はさらに別途、派遣元誓約書・派遣先誓約書・個別契約書・管理台帳等が必要。

### → 狙う順位

1. **【最優先】カテゴリー1/2の日系企業**
   - 上場SIer・中堅以上の受託開発・事業会社の社内SE
   - 更新が「書類なしで通る」＝入社直後の負担がゼロ
   - 次回の在留期間が**3年**になる可能性も上がる（今は1年）

2. **【本命職種】クラウド/インフラエンジニア**
   - **AWS3資格が唯一「換金」できるポジション**
   - 普通のJava開発職では資格は「歓迎要件」の一行だが、クラウド職では**選考通過の武器**になる
   - 人手不足が激しく、「日本経験が短い」というハンデを乗り越えやすい
   - **「収入が最も高いところ」への最短経路は、高い会社を狙うことではなく、人が足りない職種を狙うこと**

3. 【次点】事業会社の社内SE（上流経験が直結・残業少・安定）

4. 【機会型】自社開発/Web系（コーディング量を深掘りされる＝一番弱い部分。少数だけ出して練習台に）

### ❌ 明確に除外

- **小規模SES・派遣会社**（今と同じ問題の繰り返し＋更新が茨の道）
- 外資（英語スコアなし）
- 大手SIer本体（新卒文化が強く中途の壁が高い）
