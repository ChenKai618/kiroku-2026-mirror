## 📌 この職務経歴書についての解説（お前だけが読む部分）

### なぜ「大したことない」と思っている案件がこう書けるのか

お前は「毎日暇で何もしてない」と言った。それは**忙しさの話**であって、**経歴の話ではない**。

職務経歴書が記録するのは：
- どの**業界**のシステムか → 金融（損害保険）
- どの**工程**を経験したか → 外部設計・内部設計・UT（＝上流から下流まで）
- どんな**技術**に触れたか → Java / Thymeleaf / AWS EC2
