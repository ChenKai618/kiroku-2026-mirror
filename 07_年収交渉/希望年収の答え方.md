# 年収交渉 — 希望年収の答え方とオファー面談

> **この文書が、この10週間で最も金額に直結する。**
> 面接の出来が同じでも、この答え方一つで年収が50〜100万変わる。

---

## 🔴 最重要ルール：先に数字を言った側が負ける

日本の転職では、年収は**オファー面談**で決まる。それまでは全部前哨戦だ。

**ルール**：
1. **履歴書に希望年収を書かない** → 「貴社規定に従います」
2. **一次・二次面接で数字を出さない** → 聞かれたらレンジで答える
3. **エージェントには本音を言う** → 彼らは高く売りたい。味方
4. **数字を確定させるのはオファー面談** → ここで初めて具体的に交渉

**理由**：早い段階で「400万」と言うと、**それが上限になる**。
企業は「400万で来る人」に450万を出さない。出す理由がない。

## 📊 お前の現状と目標（数字の整理）

| 項目 | 金額 |
|---|---|
| 現在の月給（額面） | **250,000円** |
| 賞与 | **なし**（契約書第4条は「面談により決定」＝保証ゼロ） |
| **現年収** | **300万円** |
| お前の希望最低ライン | 400万円（+33%） |
| 交渉時に提示する希望額 | **450万円** |

### 「300万」を伝えるとき、必ずセットで言うこと

**現年収を正直に言うのは必須**（源泉徴収票で確認される可能性がある）。
だが**裸で「300万です」と言うな。** 必ず理由を添える。

```
「現在は300万円です。

来日の際に『日本での実務経験がゼロだから』ということで、
新卒と同じ条件で入社しております。

そのため、現在の年収は私の経験やスキルを反映したものではなく、
来日時点の事情によるものだと考えております。」
```

**この一文がないと、企業は「300万の人」と認識する。**
**あると、「事情で300万になっている人」と認識する。** 提示額が変わる。

## 🎤 場面別の答え方

### 場面1：エージェント面談（初回）

**ここでは本音を言え。** エージェントは年収の30〜35%が報酬なので、
**お前の年収を上げたいというインセンティブを持っている。**

```
「現在が300万円です。

来日時に『日本での経験がゼロだから』と新卒と同じ条件で入社していて、
市場水準と比べてどうなのかを正直に把握できていません。

まず、私の経験とスキルで市場ではどのあたりが妥当なのか、
プロの目線で教えていただけますか。

希望としては450万円程度を目指したいと思っておりますが、
現実的にどうかも含めてご意見をいただきたいです。」
```

**3社に同じことを聞け。** 3つの答えが返ってくる。それが相場だ。
**これはタダで市場価格を知る唯一の方法。**

---

### 場面2：一次・二次面接で「希望年収は？」と聞かれた

**ここで確定的な数字を出すな。** レンジで答えて、判断を後ろに送る。

```
「現在は300万円ですが、これは来日時に
実務経験がゼロという前提で新卒と同じ条件で入社したためで、
経験を反映した金額ではないと考えております。

希望としては、400万円台を目安に考えております。

ただ、業務内容やお任せいただける範囲によっても変わりますので、
まずはお話を伺ってから、
改めてご相談させていただければと思っております。」
```

**設計**：
- レンジ（400万台）で答える → 幅を残す
- 「まずはお話を伺ってから」→ **交渉を後ろに送る**
- 「業務内容によって変わる」→ 金だけの人ではないと示す

**もし「具体的にいくら？」と押し込まれたら**：
```
「450万円を希望しております。
ただ、御社の給与体系に合わせて柔軟に考えたいと思っております。」
```
> 450と言え。400ではなく。**下がる方向にしか動かないから、上から入る。**

### 場面3：オファー面談（★本番）

内定後、条件を提示される場。**ここが交渉の唯一の本番。**

#### まず絶対に確認する4つ

```
1. 「提示いただいた年収の内訳を教えていただけますか。
    基本給と賞与の比率はどのようになっていますか」

2. 「賞与は何ヶ月分が想定されていますか。
    業績連動の場合、直近の実績を教えていただけますか」

3. 「固定残業代（みなし残業）は含まれていますか。
    含まれる場合、何時間分でしょうか」

4. 「昇給はどのようなサイクルと基準で行われますか」
```

**なぜこの4つが必須か**：

日本の求人票の「想定年収400万円」には**罠がある**：

| 内訳パターン | 実質 |
|---|---|
| 基本給25万×12 + 賞与4ヶ月 = 400万 | ✅ 健全 |
| 基本給28万×12 + 賞与2ヶ月 = 400万 | ✅ 月々の手取りは多い |
| 基本給25万（うち固定残業45時間分5万込み）×12 + 賞与4ヶ月 | ⚠️ **実質の基本給は20万**。残業しても45時間まで追加ゼロ |
| 基本給33万×12 = 400万（賞与なし） | ⚠️ 賞与ゼロ。景気に強いが上がりにくい |

**「固定残業代が何時間含まれているか」を聞かないと、実質時給が分からない。**
これは聞いていい質問だ。むしろ聞かないと「条件を読めない人」に見える。

#### 交渉の切り出し方（提示額が希望を下回った場合）

```
「ご提示いただきありがとうございます。
ぜひ御社で働きたいという気持ちは強く持っております。

一点、年収についてご相談させていただけますでしょうか。

現在いただいている他社様からのご提示や、
エージェント様から伺っている市場水準を踏まえますと、
◯◯◯万円程度でご検討いただくことは可能でしょうか。

金額だけの問題ではなく、
長く働かせていただく前提での納得感という意味でのご相談です。」
```

**設計**：
- **必ず「入社したい」を先に言う** → 交渉が「金次第で断る」に見えない
- **他社提示・市場水準**を根拠にする → 感情ではなく事実
- 「納得感」→ 長期就業の意思を示す

**⚠️ 嘘の他社オファーを作るな。** 「エージェントから伺っている市場水準」で十分。
ビズリーチのスカウトに具体額があれば、**それは事実として使える。**

#### 上がらなかった場合の第二の交渉材料

年収が動かなくても、他に交渉できるものがある：

```
「年収について難しいということであれば、
以下についてご相談できますでしょうか。

・入社時の等級・グレードの見直し
・初回の昇給タイミングを半年後にしていただく
・資格取得支援（AWS認定の受験料補助）
・リモートワークの頻度」
```

**特に「資格取得支援」は聞け。** お前は今の会社でこれを拒否された。
AWS試験は1回3〜4万円（SAPは約4万円）。年2回受ければ8万円。
**これは実質的な年収アップだ。** そして企業側は年収より出しやすい。

## 📄 労働条件通知書を必ず書面で

**口約束は無効。** 必ず書面（労働条件通知書 or 雇用契約書）で受け取る。

### チェックリスト

- [ ] **基本給**（月額・円）
- [ ] **固定残業代の有無と時間数**（含まれる場合、基本給と分けて記載されているか）
- [ ] **賞与**（月数 or 算定方法・支給時期）
- [ ] **想定年収**（総額）
- [ ] **雇用形態**（**正社員** — ここを絶対に確認）
- [ ] **試用期間**（期間・その間の条件が下がらないか）
- [ ] **勤務地**（在宅の可否・転勤の有無）
- [ ] **所定労働時間**（1日何時間・週何日）
- [ ] **通勤交通費**（全額 or 上限額）
- [ ] **社会保険**（健康保険・厚生年金・雇用保険・労災）
- [ ] **年次有給休暇**（初年度の付与日数と付与時期）
- [ ] **退職に関する規定**（何ヶ月前の申し出か）
- [ ] **競業避止義務の有無**

> ⚠️ **今の契約書には有給の記載が一切なかった**（労基法39条で当然発生するが）。
> **書いていない項目は後で揉める。** 書面で確認しろ。

### 🚩 危険な条件（今の会社で経験済みのはず）

| 記載 | 意味 |
|---|---|
| 「雇用形態：契約社員」 | **正社員希望なら断れ。** 同じ問題の繰り返し |
| 「賞与：会社業績により決定」（月数なし） | 実質ゼロの可能性。今の契約書と同じ書き方 |
| 「固定残業代 月80時間分」 | **過労死ラインに近い。避けろ** |
| 「就業場所：関東地域」（曖昧） | 派遣・SESの可能性。**具体的な就業場所を確認** |
| 「研修費用の返還義務」 | 辞めるときに金を請求される条項。**確認して、あれば削除交渉** |
| 「自宅待機期間は無給」 | SES特有。**案件がないと収入ゼロ** |

年収400万の手取りは、だいたい**310〜320万円**（月26万前後）。

| 年収 | 手取り目安 | 現在との差（月） |
|---|---|---|
| 300万（現在） | 約240万 | — |
| 400万 | 約315万 | **+約6.3万/月** |

※東京都・独身・扶養なしの概算。住民税は前年所得で決まるので初年度は少し安い。

> 💡 **年収が上がると、在留資格の更新でも有利になる。**
> 上陸基準省令は「日本人が従事する場合に受ける報酬と同等額以上」を要件としており、
> **これは更新時にも原則審査される。** 300万は正直ギリギリのラインだ。

## 🧠 交渉で忘れるな：お前には「更新」というカードがある

**11月30日に契約が満了する。だが更新もできる。**

これは交渉において**極めて強いカード**だ。なぜなら：

- **「内定がないと生きていけない」状態ではない** → 安いオファーを断れる
- 断れる人間は、**交渉のテーブルで足元を見られない**

**逆に言えば** — この事実を忘れると、10月末に焦って350万のオファーを受ける。
**それは今より50万高いだけで、また同じ問題を繰り返すことになる。**

```
最低ライン：400万（これを下回るなら、更新して来年もう一度勝負する方が正しい）
目標：      450万
```

**この数字を今のうちに紙に書いて、決めておけ。**
オファーを見た後に決めると、目の前の数字に引っ張られる。

## 📞 交渉の実務メモ

- **交渉はメールでもいい**（口頭が苦手なら文面の方が有利。落ち着いて書ける）
- **エージェント経由なら、エージェントに交渉させろ** — それが彼らの仕事で、しかも彼らの報酬も上がる
- **回答期限を勝手に短くされたら** →「家族と相談したいので、○日までお時間いただけますか」で普通に通る
- **内定承諾は書面/メールで**（日付を記録）
- **承諾後の撤回は法的には可能**だが信用を失う。慎重に決めろ
- **複数内定は正直に伝えていい** → むしろ交渉力が上がる

## ⚠️ 現年収を偽るな

「300万」を「380万」と偽って交渉したくなるかもしれない。**やめろ。**

理由（道徳ではなく実務）：
1. **入社時に源泉徴収票の提出を求められる**（年末調整のため。同一年内の転職なら必須）
2. そこに前職の支払金額が書いてある。**バレる**
3. 内定後にバレると内定取消の理由になりうる（2024年の東京高裁判例：経歴詐称による内定取消し有効）

**代わりに使う武器**：
- 「新卒条件で入社した」という**事情の説明**（これが本当の武器）
- ビズリーチのスカウト提示額（**事実**）
- エージェントから聞いた市場水準（**事実**）

**事実だけで十分に戦える。** お前の持ち札は本当に悪くない。
