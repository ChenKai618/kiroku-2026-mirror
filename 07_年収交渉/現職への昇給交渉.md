## 🎯 なぜ今回は前回と違うのか

### 前回（来日1.5ヶ月時点）が失敗した理由

お前が送った文面を分析する。**内容ではなく、構造に問題があった。**

| 書いたこと | 何が起きたか |
|---|---|
| 「不好意思」「挺不好意思开口」「厚着脸皮」「过意不去」 | **4回謝った**。謝る人は、断られる前提で話している |
| 「我知道自己刚来一个半月」 | **拒否理由を自分で提供した** |
| 「现场这阵子刚好走流程没啥活」 | **2つ目の拒否理由を自分で提供した** |
| 「马上要搬家了」「对在日本生活方面上花销有个了解」 | **自分の必要**を根拠にした。会社は必要には払わない |
| 「能不能帮我调整到30万？」 | Yes/Noの二択にした。**逃げ道が一つもない** |

老板の返信を読み返せ。彼は**お前が提供した理由をそのまま使った**：

> 「现在才进现场不到2个月就提涨薪的话，说实话公司有公司的制度的。」
> ← お前が書いた「我知道自己刚来一个半月」がそのまま返ってきている

### だが、老板は自分で日付をくれた

> **「一般正社员的话是第一年涨2次，半年一次。」**

**お前が現場に入ったのは2026年4月1日。半年は2026年9月30日。**

これは決定的だ。前回は「制度」で断られた。
**今回は、その制度が定めた時点が来た、という話になる。**

厚かましいお願いではない。**約束された評価時点の実行依頼だ。**

### なぜ10月から反映させたいのか（重要）

10月中旬〜下旬、お前は転職先とオファー面談をする。

そのとき言えるのが：
- 「現在の月給は25万円です」 → 年収300万が交渉の起点
- **「現在の月給は30万円です（10月に昇給）」** → **年収360万が交渉の起点**

**この差は、最終的な提示額に数十万円の差を生む。**

> ⚠️ 嘘は書くな。昇給が実現した場合のみ、この数字を使う。
> 給与明細で証明できる状態にしておくこと。

## 🎤 交渉の文面（微信/メッセージ用・中国語）

**送る前に3回読んで、謝罪の言葉が入っていないか確認しろ。**

```
峰哥，有件事想正式跟您谈一下，方便的时候看一下就行。

上次聊薪资的时候您说过，正社员第一年是半年一次评价。
我是4月1日进的现场，到这个月底刚好满半年，
所以想按照这个时点，跟您正式谈一次。

这半年在现场，我的情况是这样的：

一个是工程上，从现行系统的代码解析开始，
内部设计、外部设计都参与了，UT的仕様書和实施也做完了。
设计书都是我自己用日语写的，没有让别人帮忙翻译过。

另一个是技术上，因为现场是AWS移行案件，
基盘那边负责AWS，但开发这边不理解移行后的构成的话，
设计判断上会有跟不上的地方，
所以我把AWS的认证从CLF、SAA一直考到了SAP。
SAP是Professional级别，在日本的现场里持有的人不多。

基于这半年的交付，想请您考虑把基本报酬调整到30万。

如果30万这个数字这次有难度的话，
也想请您考虑下面几个方案中的任何一个：

一、资格手当——AWS的三个认证按月给一个固定的手当
二、之前说的资格考试费用报销，按您方便的方案落实一下
三、如果这次调整不了，希望能明确下次评价的时点和标准，
    这样我自己也好有个准备的方向

您方便的时候回复就行，不着急。
```

### この文面の設計

| 要素 | 意図 |
|---|---|
| 冒頭に謝罪なし | 権利の話をしている。謝る場面ではない |
| **「您说过…半年一次评价」** | **彼自身の言葉を根拠にした。反論しにくい** |
| 「4月1日进的现场，到这个月底刚好满半年」 | 事実の提示。感情ゼロ |
| 工程の列挙（設計→UT） | **成果**を語っている。必要ではなく |
| 「设计书都是我自己用日语写的」 | 他の中国人エンジニアとの差別化。**具体的で検証可能** |
| AWSの理由を業務に紐付け | 「資格マニア」批判を先に潰す |
| 「SAP…持有的人不多」 | 希少性の主張。だが控えめに |
| **3つの代替案** | ★**Yes/Noの二択にしない。** 断るときも何か出しやすくなる |
| 「不着急」 | 圧をかけない。だが引かない |

### 🔴 絶対に書くな

- ❌ 謝罪の言葉（不好意思／厚着脸皮／过意不去）
- ❌ 「刚来不久」「才半年」などの自己減点
- ❌ 「现场没什么活」（**前回これで殺された**）
- ❌ 引っ越し・生活費・年齢の不安（＝自分の必要）
- ❌ 他人との比較（「同じ現場の○○さんより低い」）← **最も危険**
- ❌ 転職をほのめかす言葉（「不然我可能要考虑…」）

最後の項目が特に重要。**転職を匂わせた瞬間、第5条（自宅待機・無給）のリスクが現実になる。**

## 🛡 むしろ、この交渉は「カモフラージュ」になる

考えてみろ。**転職を決めている人間は、現職の給与交渉をしない。**

9月〜10月はお前が最も多く面接を受ける時期で、最も疑われやすい時期だ。
そのタイミングで昇給交渉をしているお前は、老板の目にどう映るか。

**「この会社で長くやろうとしている人間」に見える。**

これは意図的な嘘ではない。**昇給交渉は本当にする。結果次第で何かが変わるかもしれない、と一瞬でも思うなら、それは誠実な交渉だ。**
ただ、結果として最も自然な煙幕にもなる。

## 🚫 だが「昇給したら残る」は、絶対にダメだ

**お前が書いた「如果提了同意的话是不是也可以考虑留到明年更新签证」——
これがこの相談で最も危険な考えだ。理由は金ではない。**

### 仮に30万（年収360万）になったとして、残った場合に起きること

| 表面上の得 | 実際 |
|---|---|
| 年収+60万 | だが**賞与は依然として保証ゼロ**（第4条「面談により決定」） |
| 転職の手間が省ける | だが**28歳が29歳になる** |
| 慣れた環境 | **同じ社長。3万円の資格費用を渋った人** |
| ビザが平穏に更新 | ❌ **ここが最大の問題** ↓ |

### 🔴 ビザの問題（金より重い）

**今のお前の在留期間は「1年」だ。3年でも5年でもなく、1年。**

入管が1年しか出さないのは、お前の問題ではなく、**所属機関の規模と安定性の評価**による。
台東区の小さなビルにある派遣会社は、1年しか出ない。

残った場合に起きること：

1. **毎年、更新申請を繰り返す**
2. 毎回、この会社に**決算文書・登記事項証明書・会社案内**を出してもらう交渉が必要（カテゴリー3/4のため）
3. **派遣形態の就労はさらに追加書類**：派遣元誓約書・派遣先誓約書・労働者派遣個別契約書・派遣元/派遣先管理台帳・就業状況報告書
4. そして最大の問題 — **永住許可申請は「現に有する在留期間が3年以上」が要件。1年更新を繰り返す限り、永住の道は閉じたままになる**

**カテゴリー1/2の企業に移れば、更新は原則書類なしで通り、次回3年が出る可能性が上がる。**

### だから、こう決めておけ

```
┌─────────────────────────────────────────┐
│  昇給交渉の結果は、転職計画を変えない。      │
│                                          │
│  昇給した   → 良し。現年収の交渉起点が上がる │
│  昇給しない → 良し。天井を確認できた         │
│                                          │
│  どちらでも、10月末に内定があれば更新しない。 │
└─────────────────────────────────────────┘
```

**この一文を、交渉する前に決めておけ。**
交渉した後に決めようとすると、目の前の数字に引っ張られる。

### 🔴 最も可能性が高い新条項：資格取得費用の返還義務

**現行契約には、この条項が「ない」。**（俺は確認した）

だが考えてみろ。老板の直近の体験は：
- 従業員が1ヶ月でAWS 3つ取った
- 受験料の請求が来た（SAPだけで約4万円）
- 「考太快、考太多」と言い、限度額を設けると言った

**この経験をした経営者が、契約を巻き直すときに最も自然に入れる条項は何か。**

```
「会社が費用を負担した研修・資格取得について、
 取得後○年以内に退職した場合、
 費用の全部または一部を返還するものとする」
```

これを署名したら、**今後お前が資格を取るたびに足枷が増える。**

### 更新契約で逐条確認すべきリスト

| 条項 | 現行 | 新契約で確認 |
|---|---|---|
| **資格取得費用の返還義務** | **なし** ✅ | ★**最も追加されやすい。あれば削除交渉** |
| **競業避止義務** | なし ✅ | 追加されると同業への転職が制限される |
| 退職の申し出期間 | 30日（第6条） | 60日・90日に延長されていないか |
| 損害賠償（第7条①） | 「一切の損害」（抽象的） | 具体的な金額や算定式が入っていないか |
| 入管への情報提供（第7条②） | あり | 範囲が拡大していないか |
| **自動更新条項** | なし | 「異議がなければ自動更新」＝抜けにくくなる |
| 契約期間 | 1年 | 2年等に延長されていないか（長い＝抜けにくい） |
| **雇用形態** | 契約社員 | **正社員になっているか。ならないなら昇給も空手形** |
| 賞与（第4条） | 「面談により決定」 | **月数が明記されるか。されないなら実質ゼロのまま** |
| 自宅待機（第5条） | 「無給にする場合もある」 | ※この条項自体が労基法26条に反し無効の可能性 |

### 更新する場合（Bパターン）の交渉ポイント

**更新時はお前に交渉力がある。** 現場に穴を空けたくないのは会社の方だ。

```
「更新については前向きに考えております。

一点、契約内容について確認させてください。
前回の契約から変更されている箇所があれば、
事前に教えていただけますでしょうか。

また、以下について契約書に明記いただけないでしょうか。
・賞与の支給月数
・昇給の時期と基準
・資格取得支援の取り扱い」
```

**新しい制限条項が入っていたら、その場で署名するな。**
「持ち帰って確認します」は当然の権利だ。
