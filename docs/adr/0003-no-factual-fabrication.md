# 経歴の「事実欄」は改変せず、「修辞」のみを使う

本人は当初、2019-2021年（軍での2年間のC#/WPF開発）について
架空の民間企業を記載することを検討していた。**これを採らない。**

代わりに、実際に参加した工程・成果物を日本の職務経歴書の標準的語彙で記述する
「修辞」は最大限使う（例：「設計レビューへの参加」＝実際は先輩の横で聞いていた、
「既存システムのソースコード解析」＝実際は旧コードを読んだ）。

**雇用主名・在籍期間・学歴年次・前職年収は一切動かさない。**

## 判断の根拠（道徳ではなくリスク計算）

日本人が履歴書で経歴を詐称した場合の最悪の結果は懲戒解雇である
（炭研精工事件・最判平3.9.19。学歴を**低く**偽った場合も含む。
グラバス事件・東京地判平16.12.17 はJavaの能力詐称で解雇有効）。

**外国人の場合、経路が一本多い。**
入社2ヶ月後（2026年12月〜2027年2月）に在留期間更新許可申請を提出することになり、
**申請書には学歴と職歴を記入する欄がある**。
民間の履歴書に書いた虚偽を、2ヶ月後に自分で入管の法定文書へ転記することになる。

入管法22条の4第1項第2号は「申請人が自身の経歴を偽った場合」を
在留資格取消事由として明示しており、**この号による取消には出国準備期間がなく、
直接退去強制・原則5年間の上陸拒否となる**。
さらに入管は2025年のCOE申請時に提出した書類を保管している
（ISA：「原則として、提出された資料は返却できません」）。

賭け金は「履歴書に会社名が1つ増える」、想定損失は「5年間日本に入れない」。
**このオッズでは賭けない。**

## そして、そもそも必要がない

手持ちの真正なカードが十分に強い ——
損保基幹システムのAWS移行案件（大手SIer元請）、上流工程経験、
AWS SAP/SAA/CLF、JLPT N1、ADRを書く習慣、契約満了という無敵の転職理由。

**架空の経歴は、存在しない短所を埋めるために本物の資産を危険に晒す取引になる。**

## 却下した選択肢

**架空の民間企業を記載する**：
日本企業が中国の2019年の雇用記録を検証する可能性は実務上ほぼない
（雇用保険は本体のみの提出が制度上認められ、
ハローワークは新雇用主に職歴を開示せず、
リファレンスチェックの実施率は13.5%——人事白書2025）。
**検出リスクは低い。** だが上記の入管経路が残る。

加えて運用コストがある。架空企業を記載すれば、
業種・規模・製品・自分の役割・退職理由・在職証明の可否といった
深掘りに、日本語で、圧力下で、複数社に対して一貫して答え続ける必要がある。
**「公的機関・守秘義務」は真実であるため運用コストがゼロで、
かつ会話がそこで終わる。**
