# 「契約更新」を敗北ではなく安全網として位置づける

在留期限は2027年2月28日であり、在留期間更新許可申請には
雇用契約書・在職証明書・登記事項証明書等が必須である。**無職では申請書類が揃わない。**
入管法22条の4第1項第6号の「3ヶ月ルール」は在留資格の**取消**を防ぐ規定であって
**在留期限を延長する規定ではない**ため、本件では在留期限が先に到来する。
したがって実質的な無職許容期間はゼロ。

そこで、10月31日時点で内定がない場合は**現職と契約を更新する**と事前に決めておく。
これにより次の満了は2027年11月30日となり、在留資格が維持され、活動を継続できる。

## なぜこれを明文化するのか

これは実務上の保険であると同時に、**交渉における心理的装備**である。

「内定がなければ日本にいられなくなる」状態の候補者は、
10月末に提示された350万円のオファーを断れない。
**断れない候補者は、交渉のテーブルで足元を見られる。**

「更新すれば生き延びる」と事前に確定させておくことで、
不本意なオファーを断る自由が生まれる。**この自由こそが交渉力の実体だ。**

## 却下した選択肢

**「10月末までに必ず決める」という背水の陣**：
集中力は上がるかもしれないが、判断が焦りに支配される。
本件の目的は「転職すること」ではなく「満足のいく転職をすること」であり、
前者だけを達成しても、現職と同じ問題を数年後に繰り返す。
