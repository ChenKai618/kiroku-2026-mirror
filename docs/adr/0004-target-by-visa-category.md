# 応募先を「年収」ではなく「在留資格カテゴリー」で一次選別する

転職後の初回在留期間更新において、所属機関のカテゴリーによって
提出書類が大きく変わる。カテゴリー1（上場企業等）・2（前年源泉徴収税額1,000万円以上）は
**追加書類が原則不要**。カテゴリー3・4は登記事項証明書・会社案内・決算文書・
課税/納税証明書が必要で、2026年4月15日以降はさらに
「所属機関の代表者に関する申告書」が加わる。
派遣形態での就労はこれに加えて派遣元誓約書・派遣先誓約書・
労働者派遣個別契約書・管理台帳・就業状況報告書が必要になる。

本件では入社の約2ヶ月後に更新申請が発生するため、
**入社したばかりの会社に決算書の提出を依頼する交渉**が必要になる。
よって**カテゴリー1/2を一次スクリーニングの条件とし、小規模SES・派遣は応募先から除外する。**

## 職種の優先順位

主戦場は**クラウド／インフラ職**とする。
本人のAWS 3資格（CLF/SAA/SAP）は、一般的なJava開発職の求人票では
「歓迎要件」の一行に過ぎないが、クラウド職では選考通過の武器として機能する。
また同職種は人材不足が深刻で、「日本での実務経験が短い」というハンデを越えやすい。

**「最も収入が高いところ」への最短経路は、高い会社を狙うことではなく、人が足りない職種を狙うこと。**

## 却下した選択肢

**年収レンジのみで応募先を選ぶ**：
提示年収400万のカテゴリー4企業と、380万のカテゴリー1企業では、
後者の方が総合的な価値が高い。理由は書類負担だけではない ——
現在の在留期間は**1年**であり、これは本人ではなく所属機関の規模・安定性の評価による。
カテゴリー1/2への移籍は次回3年が出る可能性を上げる。
そして**永住許可申請は「現に有する在留期間が3年以上」を要件とするため、
1年更新を繰り返す限りその道は閉じたままになる。**

**自社開発/Web系を主戦場にする**：
年収レンジは高いが、コーディング量を深掘りされる。
そこが本人の最も検証されていない領域であり
（[ADR-0006](./0006-ai-assisted-development-disclosure.md)）、
アルゴリズム系の選考も集中している。**機会型として少数のみ応募し、練習台と位置づける。**
