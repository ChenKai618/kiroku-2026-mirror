# 退出経路は「契約満了」を使う

契約書は2026年11月30日に契約期間が満了すると定めており（第1条）、
更新には双方の合意が必要と書かれている。したがって更新に同意しなければ、
契約は自然に終了する。この経路を使えば、
**第7条①（途中解約時に顧客の合意がなければ一切の損害を賠償させる条項）が適用されない。**

代わりに10月31日（満了1ヶ月前の更新意思確認）までに内定を得る必要が生じ、
準備期間が実質9週間に圧縮される。それでもこの経路を選ぶ。

## 却下した選択肢

**第6条による途中解約（30日前通知）**：時間的余裕は生まれるが、
第7条①の損害賠償と第7条②（入管への情報提供）を会社側が持ち出す余地を与える。

第7条①は法的にはほぼ無効と考えられる（労基法16条の賠償予定禁止、
憲法22条の職業選択の自由、茨城石炭商事事件・最判昭51.7.8 が示す
「信義則上相当と認められる限度」の制約）。**だが勝てることと、争わずに済むことは別だ。**
争っている間に失う時間と精神力は、9週間の圧縮より高くつく。

## 結果として受け入れる制約

- 準備期間が9週間になる。「準備してから応募」は成立せず、**応募しながら準備する**しかない
- 10月31日が絶対の決断日になる
- ただし**更新という安全網が常に存在する**（[ADR-0002](./0002-renewal-as-safety-net.md)）
