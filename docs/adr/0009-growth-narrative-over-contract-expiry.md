# 転職理由は「成長の物語」を主体にし、契約満了は補足に降格する

面接での転職理由は、当初「契約期間の満了が最も大きな理由です」から始める構成にしていた。
**これを変更する。** 成長の物語（設計工程の完遂 → クラウドへの関心 → 基盤側に踏み込みたい）を
主体に置き、契約満了は最後に一文だけ添える形にする。

本人からの指摘による変更：
「契約満了を冒頭に置くと、期限が来たから動く人＝**消極的な理由**に聞こえる」。
これは日本の面接の評価軸として正しい。転職理由に期待されるのは
**前向きな理由**（どこへ行きたいか）であって、消極的な理由（どこから押し出されたか）ではない。

## だが削除はしない

契約満了は、**短期離職（在籍5ヶ月）の懸念を消せる唯一の材料**である。
成長の物語をどれだけ語っても、面接官の「しかしまだ5ヶ月では」という疑念は自然には消えない。

そこで役割を分割する：

- **成長の物語** → 「なぜ移りたいか」を担当（主体）
- **契約満了** → 「なぜ今か」を担当（最後の一文）

順序を入れ替えるだけで、同じ事実が消極的理由から時期の説明に変わる。

## この変更が生む新しいリスクと、その対策

成長を理由にすると、面接官はほぼ確実にこう返す：
**「では、今の会社ではその希望は叶わないのですか？」**

契約満了を主体にしていた旧版では、この追問は発生しなかった（理由が外部要因だったため）。
ここで詰まると、直前に語った成長の物語が全て言い訳に聞こえる。

対策として、SESの構造を悪口なしで説明する回答を用意した
（`05_面接/想定問答集.md` Q1 の追問対策）。
「基盤チームは別会社」「次の案件は状況次第」は**事実の記述であって不満の表明ではない**が、
聞いた側は「この人は今の場所ではキャリアを設計できない」と自分で結論する。

## 併せて確定した事実の扱い

**「来日1年」と言わない。** 2026年3月頃に来日、4月1日に現場入りであり、
面接時点で在日約6ヶ月・現場5〜7ヶ月。

数字を盛る利益がゼロである一方、「いつ来日されましたか」の一問で崩れる。
そもそも不要でもある ——「短期間でここまで」の方が学習速度の証明として強い。
[ADR-0003](./0003-no-factual-fabrication.md) の事実欄不可侵の原則がここにも適用される。
