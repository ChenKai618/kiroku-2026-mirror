# 現職への昇給交渉は行う。ただし結果は転職判断に影響させない

2026年9月中旬〜下旬に、現職へ昇給交渉を提出する。
根拠は社長自身の発言「一般正社員は第一年に2回、半年に1回昇給」であり、
本人は4月1日に現場入りしているため9月30日で半年を迎える。
**彼が「制度」を理由に前回拒否した以上、その制度が定めた時点の到来は交渉の正当な根拠になる。**

**ただし、結果がどうであれ転職計画は変更しない。** これを交渉前に確定させる。

## なぜ「昇給しても残らない」と事前に決めるのか

仮に30万円（年収360万）に上がっても、残留の判断は変わらない。理由は金額ではない。

現在の在留期間は**1年**である。これは本人の評価ではなく
**所属機関の規模・安定性の評価**による。残留した場合：

- 毎年更新申請を繰り返し、毎回この会社に決算文書等の提出を依頼する必要がある
- 派遣形態の就労には追加で誓約書・個別契約書・管理台帳等が必要
- **永住許可申請は「現に有する在留期間が3年以上」を要件とするため、
  1年更新を繰り返す限りその道は閉じたままになる**

カテゴリー1/2への移籍は次回3年の可能性を上げる（[ADR-0004](./0004-target-by-visa-category.md)）。

**この判断を交渉前に固定するのは、交渉後に決めようとすると
目の前の数字に判断が引っ張られるためである。**

## 交渉自体の価値（金額ではない）

1. **オファー面談での交渉起点が上がる。** 現年収300万と360万では、提示額に数十万の差が生まれる
2. **情報が取れる。** 社長の回答が、この会社が本人をどう評価しているかを明らかにする
3. **カモフラージュとして機能する。** 転職を決めている人間は現職の昇給交渉をしない。
   9〜10月は面接が最も多く最も疑われやすい時期であり、
   昇給交渉中の本人は「この会社で長くやろうとしている人間」に見える

## 前回の失敗から変更した点

前回（来日1.5ヶ月時点）の交渉文面は、構造上の欠陥により失敗した：

- 謝罪を4回述べた
- 「まだ来て1ヶ月半」「現場に仕事がない」と**拒否理由を自分で提供した**
  （社長の返信はこれをそのまま引用している）
- 引っ越し・生活費・年齢という**自分の必要**を根拠にした
- 「30万にしてほしい」という**Yes/Noの二択**にした

今回は謝罪ゼロ、成果の列挙（設計工程の完遂・日本語での設計書作成・AWS 3資格）、
そして**3つの代替案**（資格手当／受験料報銷／次回評価時点の明確化）を提示する。
**二択にしないことで、主要求を断る際に副次的な要求を通しやすくする。**
