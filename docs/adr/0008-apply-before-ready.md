# 準備の完了を待たずに応募を開始する

書類・コード理解・面接練習が完成する前に、エージェント登録と応募を開始する。

## 根拠は時間軸の重なりにある

決断日（10月31日）まで9週間しかなく、日本の転職プロセスは平均3ヶ月を要する。
**「準備してから応募」を選ぶと、応募を開始した時点で決断日が過ぎている。**

一方、プロセスの構造上、準備と選考は重なる：

```
応募 → 書類選考（1〜2週間・技術は問われない）
     → 一次面接（3〜4週間後・経歴と人柄が中心）
     → 二次面接（技術の深掘りはここから）
```

**技術を深掘りされるのは応募の3〜4週間後**であり、
無AI訓練（3週間）とADR読解（1〜2週間）はその間に完了する。
**「応募しながら準備する」は妥協ではなく、時間軸的に正しい順序である。**

## より根本的な理由

本人には「完全な安全が確認されるまで行動を許可しない」という行動様式がある。
この様式の下では、準備項目を一つ完了するたびに次の不安が対象を見つけるため、
**「準備完了」の状態は原理的に到達しない。**

したがって応募の判断基準から不安を除外する。判断は以下のみで行う：

- 職種の方向が合っているか
- 要件の50〜70%を満たしているか
- その仕事をやりたいか
- 条件が試す価値のあるものか

**自分から見送ってよいのは、明確に範囲外の求人のみ**
（機械学習の研究職・競技プログラミングの実績が必須・
モデルをゼロから学習させる仕事・そもそもやりたくない仕事）。
それ以外は**企業に判断させる。**

## 自己校正は市場で行う

自分の市場価値は自宅では判明しない。

- 書類が全く通らない → 職務経歴書の問題。エージェントに添削させる
- 面接でプロジェクト説明に詰まる → コード理解を強化
- 基礎コーディングで落ちる → 無AI訓練を延長
- **アルゴリズムを問われない** → 恐怖の対象が実在しなかったと判明する

本人の応募先構成（クラウド/インフラ40%・SIer 27%・社内SE 20%・自社開発13%）では、
**最後のパターンになる確率が最も高い。**
アルゴリズム選考は自社開発・メガベンチャー・外資に集中しており、
本件の主戦場ではない。

**頭の中の100回のシミュレーションより、1回の実際の面接の方が正確な情報を返す。**
